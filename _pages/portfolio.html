Manapy — Parallel Finite Volume Solver

Manapy — Solveur par Volumes Finis Parallèle

GitHub: https://github.com/imadki/manapy

Role:Rôle : Initiator and main developer

Manapy is an open-source Python library for parallel resolution of partial differential equations (PDEs) using the finite volume method on unstructured meshes. It supports a wide range of physical models including Shallow Water equations, Navier-Stokes equations, Magnetohydrodynamics (MHD), viscoplastic flows, and flow in fibrous media. The library is built on top of MPI4py for distributed memory parallelism, allowing simulations on clusters and supercomputers.

Manapy est une bibliothèque Python open-source pour la résolution parallèle d'équations aux dérivées partielles (EDP) par la méthode des volumes finis sur maillages non-structurés. Elle supporte une large gamme de modèles physiques : équations de Saint-Venant, Navier-Stokes, Magnétohydrodynamique (MHD), écoulements viscoplastiques et en milieux fibreux. La bibliothèque est basée sur MPI4py pour le parallélisme à mémoire distribuée, permettant des simulations sur clusters et supercalculateurs.

Current Users:Utilisateurs actuels : Master's and PhD students, as well as researchers and faculty from UM6P, USPN, ULHN, Groupe de Recherche en Génie Electrique de Paris, and CentraleSupélec.

Mumps4py — Python Interface for the MUMPS Parallel Solver

Mumps4py — Interface Python pour le Solveur Parallèle MUMPS

GitHub: https://github.com/imadki/mumps4py

Role:Rôle : Designer and main maintainer

Mumps4py is an open-source Python interface for the parallel sparse direct solver MUMPS (MUltifrontal Massively Parallel Solver). It has been officially adopted by the MUMPS project and integrated into distributed HPC workflows. The library allows Python users to directly leverage the power of MUMPS for solving large sparse linear systems in parallel, making it accessible for scientific computing applications in CFD, structural mechanics, and more.

Mumps4py est une interface Python open-source pour le solveur direct creux parallèle MUMPS (MUltifrontal Massively Parallel Solver). Elle a été officiellement adoptée par le projet MUMPS et intégrée dans les workflows HPC distribués. La bibliothèque permet aux utilisateurs Python d'exploiter directement la puissance de MUMPS pour résoudre de grands systèmes linéaires creux en parallèle, la rendant accessible pour des applications de calcul scientifique en CFD, mécanique des structures, et plus.

Official MUMPS page:Page officielle MUMPS : https://mumps-solver.org/index.php?page=links

Current Users:Utilisateurs actuels : Master's and PhD students, researchers and faculty from UM6P, USPN, ULHN, as well as the industrial group Safran.

NeuralPDE-Solver — Physics-Informed Neural Networks Framework

NeuralPDE-Solver — Framework de Réseaux de Neurones Physiquement Informés

GitHub: https://github.com/Mohammed-khlifi/NeuralPDE-Solver

Role:Rôle : Initiator and main developer (initial design and architecture)

NeuralPDE-Solver is an open-source Python framework designed to apply deep learning techniques to the resolution of steady-state partial differential equations (PDEs). It supports Physics-Informed Neural Networks (PINNs), Physics-Informed Neural Operators (PINOs), and Fourier Neural Operators (FNOs). The framework provides a modular design that allows researchers to easily develop and integrate new PINN architectures, loss functions, or governing equations for customized PDE problems. Development was initiated by Imad Kissami and later continued as part of a supervised Master's thesis project.

NeuralPDE-Solver est un framework Python open-source conçu pour appliquer les techniques d'apprentissage profond à la résolution d'équations aux dérivées partielles (EDP) en régime stationnaire. Il supporte les réseaux de neurones physiquement informés (PINNs), les opérateurs neuronaux physiquement informés (PINOs) et les opérateurs de Fourier neuronaux (FNOs). Le design modulaire permet aux chercheurs de développer et intégrer facilement de nouvelles architectures. Le développement a été initié par Imad Kissami puis poursuivi dans le cadre d'un projet de Master supervisé.
