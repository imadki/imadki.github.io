## Mumps4py: Python Interface for the MUltifrontal Massively Parallel Sparse Direct Solver (MUMPS)

**GitHub:** [https://github.com/imadki/mumps4py](https://github.com/imadki/mumps4py)

**Role:** Designer and main maintainer

**Description:**
Mumps4py is an open-source Python interface for the parallel sparse direct solver MUMPS (MUltifrontal Massively Parallel Solver). It has been **officially adopted by the MUMPS project** and integrated into distributed HPC workflows.

The library allows Python users to directly leverage the power of MUMPS for solving large sparse linear systems in parallel, making it accessible for scientific computing applications in CFD, structural mechanics, and more.

**Official MUMPS page:** [https://mumps-solver.org/index.php?page=links](https://mumps-solver.org/index.php?page=links)

**Current Users:**
Master's and PhD students, researchers and faculty from UM6P, USPN, ULHN, as well as the industrial group Safran.
