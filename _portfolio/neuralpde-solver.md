## NeuralPDE-Solver: Open-Source Tool for Neural Approaches to PDEs

**GitHub:** [https://github.com/Mohammed-khlifi/NeuralPDE-Solver](https://github.com/Mohammed-khlifi/NeuralPDE-Solver)

**Role:** Initiator and main developer (initial design and architecture)

**Description:**
NeuralPDE-Solver is an open-source Python framework designed to apply deep learning techniques to the resolution of steady-state partial differential equations (PDEs). It supports:

- **Physics-Informed Neural Networks (PINNs)**
- **Physics-Informed Neural Operators (PINOs)**
- **Fourier Neural Operators (FNOs)**

The framework provides a modular design that allows researchers to easily develop and integrate new PINN architectures, loss functions, or governing equations for customized PDE problems.

Development was initiated by Imad Kissami and later continued as part of a supervised Master's thesis project (Mohammed Khlifi, QFM, UM6P).
