<div class="lang-en-block" markdown="1">
**Institution:** [UM6P College of Computing](https://cc.um6p.ma/), Ben Guerir, Morocco

Introduction to modern C++ programming with a focus on the C++17 standard. Covers fundamental and advanced concepts including object-oriented programming, templates, the Standard Template Library (STL), smart pointers, and move semantics. Special attention is given to C++17 features such as structured bindings, if constexpr, fold expressions, and lambda function improvements. Students gain practical experience in memory management, generic programming, and building efficient, reusable code.

## Curriculum Overview

**Part I — Foundations**

- Getting Started
- Structure of a C++ Program
- Variables and Constants
- Containers
- Expressions, Statements and Operators
- Determining Control Flow
- Strings in C++
- Functions

**Part II — Advanced C++**

- Pointers
- Lambda Functions
- Introduction to OOP
- OOP — Operator Overloading
- OOP — Inheritance
- OOP — Polymorphism
- Smart Pointers
- Exceptions
- I/O Streams
</div>

<div class="lang-fr-block" markdown="1">
**Institution :** [UM6P College of Computing](https://cc.um6p.ma/), Ben Guerir, Maroc

Introduction à la programmation C++ moderne axée sur la norme C++17. Couvre les concepts fondamentaux et avancés, notamment la programmation orientée objet, les templates, la Standard Template Library (STL), les pointeurs intelligents et la sémantique de déplacement. Une attention particulière est portée aux fonctionnalités de C++17 telles que les liaisons structurées, if constexpr, les expressions de fold et les améliorations des fonctions lambda. Les étudiants acquièrent une expérience pratique en gestion de mémoire, en programmation générique et dans la construction de code efficace et réutilisable.
